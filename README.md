# Admin Dashboard

This is a mock admin dashboard made to practice with CSS grid and HTML/CSS in general.
See the [project spec](https://www.theodinproject.com/lessons/intermediate-html-and-css-admin-dashboard)
and [live demo](placeholder).

## Retrospective

Truthfully, I feel that I resorted to some spaghetti towards the end of the project
and that it's held together by not much more than hopes and dreams. That said,
I adequately met the project requirements and it was solid practice. The key lesson
I'd like to take forward is to focus on allowing the layout to shape the design
and content when using Grid; Grid works best when designing layout-first and Flex
works best when designing content-first. I'd also like to be more conscious of
writing maintainable, semantic, and readable HTML/CSS moving forward.
